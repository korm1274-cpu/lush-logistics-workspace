LUSH Logistics Workspace를 모바일에 설치하면 일반 앱처럼 실행할 수 있습니다. 아래 주소를 복사해 모바일 브라우저에서 접속한 뒤 기기별 설치 방법을 따라주세요.

Android 설치 방법

Chrome 권장
  1. 위의 접속 주소를 복사하여 Chrome에서 엽니다.
  2. Chrome 우측 상단의 ⋮ 메뉴를 누릅니다.
  3. 설치 및 바로가기 만들기를 선택합니다.
  4. 표시되는 메뉴에서 앱 설치를 선택한 뒤 설치를 진행합니다.
  5. 설치 후 LUSH Logistics 아이콘으로 실행합니다.
현재 테스트 기기 기준으로 Chrome 메뉴의 설치 및 바로가기 만들기에서 설치를 진행합니다. 기기나 Chrome 버전에 따라 표시 문구가 조금 다를 수 있습니다.

iPhone / iOS 설치 방법

Safari 사용
  1. 위의 접속 주소를 복사하여 iPhone의 Safari에서 엽니다.
  2. 화면 하단 또는 상단의 공유 버튼을 누릅니다.
  3. 공유 메뉴에서 홈 화면에 추가를 선택합니다.
  4. 우측 상단의 추가를 누릅니다.
  5. 홈 화면의 LUSH Logistics 아이콘으로 실행합니다.
iOS는 일반 파일 다운로드 방식이 아니라 Safari의 ‘홈 화면에 추가’ 기능으로 설치합니다.

설치 후 알림 테스트

필수 확인

향후 LUSH Logistics에서 푸시 알림 기능을 사용할 예정입니다. 설치가 끝나면 아래 순서대로 알림 수신 여부를 확인해주세요.

  1. 설치한 LUSH Logistics를 실행합니다.
  2. 웹페이지 상단의 테스트 알림 버튼을 누릅니다.
  3. 테스트알람 입니다. 메시지가 표시되면 정상입니다.
  4. 알림이 오지 않는 경우 휴대폰의 설정 → 알림에서 Chrome, Safari 또는 LUSH Logistics의 알림 권한이 허용되어 있는지 확인해주세요.
  5. 브라우저에서 알림 권한 요청이 표시되면 허용을 선택해주세요.
알림 권한이 차단되어 있으면 향후 푸시 알림도 수신되지 않을 수 있으므로 설치 후 테스트를 권장합니다.
