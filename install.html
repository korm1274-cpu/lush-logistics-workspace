Android 설치 방법

Chrome 권장
  1. Chrome에서 이 설치 안내 페이지를 엽니다.
  2. 상단의 Android 설치 버튼을 누릅니다. 설치 창이 뜨면 설치를 선택합니다.
  3. 버튼으로 설치 창이 뜨지 않는 경우 Chrome 우측 상단 ⋮ 메뉴를 누릅니다.
  4. 앱 설치 또는 홈 화면에 추가를 선택합니다.
  5. 설치 후 홈 화면의 LUSH Logistics 아이콘으로 실행합니다.
Chrome 버전에 따라 메뉴 이름이 ‘앱 설치’ 또는 ‘홈 화면에 추가’로 다르게 표시될 수 있습니다.

iPhone / iOS 설치 방법

Safari 사용
  1. iPhone의 Safari에서 이 설치 안내 페이지를 엽니다.
  2. 화면 하단 또는 상단의 공유 버튼을 누릅니다.
  3. 공유 메뉴에서 홈 화면에 추가를 선택합니다.
  4. 우측 상단의 추가를 누릅니다.
  5. 홈 화면의 LUSH Logistics 아이콘으로 실행합니다.
iOS는 일반 파일 다운로드 방식이 아니라 Safari의 ‘홈 화면에 추가’ 기능으로 설치합니다.
